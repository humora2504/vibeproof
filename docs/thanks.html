Run it

  1. Unzip it anywhere It has no dependencies and installs nothing.
  2. Point it at your project
    node vibeproof-fix.js /path/to/your/project
    It reads your SQL migrations and writes rls_policies.sql, rls_tests.mjs, REPORT.md, ci.yml and the playbooks into a vibeproof-fix folder.
  3. Read REPORT.md first It lists every table, which column it took to be the owner, and which tables it could not classify. Those are set to deny everything until you decide.
  4. Apply the SQL to a branch or a copy
    psql "$DATABASE_URL" -f vibeproof-fix/rls_policies.sql
  5. Prove it
    npm i @supabase/supabase-js
SUPABASE_URL=... SUPABASE_ANON_KEY=... SUPABASE_SERVICE_ROLE_KEY=... \
  node vibeproof-fix/rls_tests.mjs
    Run this against a development or branch database: it creates and deletes rows and two throwaway users.
  6. Stop it regressing Copy ci.yml to .github/workflows/vibeproof.yml.
